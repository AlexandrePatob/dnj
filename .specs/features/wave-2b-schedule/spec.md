# Onda 2B — Programação

## Requisitos

- P05: todos os textos visíveis ao participante usam “Programação”, nunca “Cronograma”.
- P06: a Programação completa possui abas Agora e Espaços.
- Agora exibe atividades live e upcoming da API real.
- Espaços agrupa atividades em accordions, na ordem Palco Principal, Santidade, Radicalidade e Meditativo, com ordem cronológica interna.
